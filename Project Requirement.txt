Project Overview: What is BeautyLink?

BeautyLink (with backend database beautylink) is an on-demand beauty, spa, and salon appointment booking marketplace platform (similar to Fresha, Treatwell, or ClassPass). It connects end-users with verified local beauty salons, spas, hair salons, skin clinics, and nail studios across major Vietnamese cities (TP. Hồ Chí Minh, Hà Nội, Đà Nẵng).
Core Capabilities:

    Discovery & Search: City and district filtering, category browsing (Spa, Massage, Thẩm mỹ viện, Chăm sóc da, Salon tóc, Nail, Clinic), price filtering, and flash deals with countdown timers.

    Online Booking System: Time slot selection, specialist preference, customer details validation, and booking code generation (BP-XXXXXX).

    Cart & Vouchers: Adding multiple beauty deals to a slide-over cart drawer and redeeming promotional discount vouchers.

    User Accounts & Loyalty: Standalone login and registration pages (#login, #register), customer account dashboard (#account) tracking loyalty points, membership tiers (Standard, Silver, Gold, VIP), and appointment history.

    Push Notification Center: Simulated and live push notifications for flash discounts, booking confirmations, and special events.

What Has Been Configured in Your React Frontend:

    Vite Proxy (vite.config.ts): Configured /api to automatically proxy requests to your local Spring Boot backend at http://localhost:8080.

    Axios Client (src/lib/api.ts): Automatically attaches JWT Authorization: Bearer <token> from localStorage on outbound requests.

    Progressive Integration (src/services/beautyApi.ts): Connected to Spring Boot /api/v1/* REST endpoints with an automatic, graceful fallback to mock data if the Java backend is offline, ensuring zero UI breakage.

1. PROJECT OVERVIEW & DOMAIN CONTEXT
--------------------------------------------------------------------------------
Project Name: BeautyLink Marketplace
Domain: Beauty, Spa, Wellness & Salon Appointment Booking Platform
Description:
  An on-demand beauty booking platform connecting customers with verified local
  salons, aesthetic clinics, spas, massage parlors, hair salons, and nail bars.
  The platform provides location-based discovery, promotional hot deals, coupon
  vouchers, loyalty rewards, instant time-slot reservation, and push notifications.

Primary User Roles:
  1. CUSTOMER: Discovers salons/deals, books appointments, tracks bookings, earns loyalty points.
  2. PARTNER (Salon Owner): Registers salon, manages services, pricing, and schedules.
  3. ADMIN: Verifies partner salons, oversees booking transactions, manages platform campaigns.

--------------------------------------------------------------------------------
2. SYSTEM ARCHITECTURE & TECHNICAL STACK
--------------------------------------------------------------------------------
Frontend:
  - Framework: React 19 SPA (TypeScript)
  - Tooling: Vite 8, Tailwind CSS v4, Motion (animations), Lucide React
  - State Management: Custom reactive store with LocalStorage hydration
  - HTTP Client: Axios with baseURL '/api'
  - Dev Server: http://localhost:3000
  - Dev Proxy: Vite server proxies '/api' -> 'http://localhost:8080'

Backend:
  - Framework: Spring Boot 3.x
  - Language: Java 21 (LTS)
  - Build Tool: Maven (pom.xml)
  - API Style: RESTful JSON endpoints (Controller -> Service -> Repository pattern)
  - Security & Auth: Spring Security 6 with stateless JWT Bearer token authentication
  - Validation: Hibernate Validator (Jakarta Validation)
  - Local Server: http://localhost:8080

Database:
  - Database Engine: MySQL 8.0+
  - Database Name: beautylink
  - Persistence Layer: Spring Data JPA with Hibernate ORM
  - Connection Pool: HikariCP
